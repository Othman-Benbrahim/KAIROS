# KAIROS — Réversibilité et généalogie

---

## Principe

Aucune résolution KAIROS n'est définitive. Toute résolution fermée est localement
stable — elle tient jusqu'à ce que de nouvelle matière narrative ou un choix
du sujet la rouvre.

La réversibilité n'est pas un dysfonctionnement. Elle est une propriété structurelle
du modèle, inscrite dès la conception : les récits humains ne se résolvent pas une
fois pour toutes. Ils se stabilisent, se rouvrent, se transforment.

---

## Mécanisme

### Étape 1 — Archivage de la résolution

Toute résolution fermée produit une entrée journal avec sa signature STÈLE :
```
⟦Trés¹_sig⟧ ◊  ← résolution fermée archivée
```

Cette signature est la mémoire compressée de l'état résolu. Elle encode
les attracteurs dominants, la trajectoire émotionnelle, et le statut de clôture.

### Étape 2 — Déclenchement de la réouverture

Conditions qui peuvent déclencher une réouverture :
- Nouvelle matière narrative (événement réel, rencontre, décision)
- Reconnaissance d'un motif récurrent ("c'est encore ça")
- Choix délibéré du sujet d'explorer un niveau plus profond
- Miroir Intégral a signalé une résolution de surface lors de la session précédente

### Étape 3 — La signature devient T0

La signature STÈLE de la résolution précédente est transmise à CRC-R
comme état hérité (Étape 0A).

```
Trés¹ → T0²
⟦Trés¹_sig⟧ devient l'état symbolique de départ du nouveau cycle
```

CRC-R charge les attracteurs hérités. NEXUS-ARCHÊ tire une nouvelle constellation
T0². LÉR-NARRATIF repart du nouveau matériau narratif.

### Étape 4 — Nouvelle session KAIROS

La nouvelle session tourne comme une session normale, avec une différence :
elle porte la mémoire de tout ce qui précède.

Les attracteurs hérités (CRC-R Étape 0A) amplifient les concepts proches
de l'histoire précédente. Les structures persistantes (NEXUS-ARCHÊ) sont visibles
dans la comparaison T0¹ vs T0².

## Chaîne généalogique

### Structure de la chaîne

Chaque cycle de réversibilité produit un maillon dans la chaîne généalogique.
L'opérateur `⊸` marque un lien résolution → réouverture.

```
⟦T0¹_sig⟧ → ⟦Tcrise¹_sig⟧ → ⟦Trés¹_sig◊⟧
                                     ⊸
⟦T0²_sig⟧ → ⟦Tcrise²_sig⟧ → ⟦Trés²_sig◊⟧
                                     ⊸
⟦T0³_sig⟧ → ⟦Tcrise³_sig⟧ → ⟦Trés³_sig↻⟧ ← résolution ouverte en T0³
```

La chaîne est archivée dans le journal. Elle permet de lire toute la trajectoire
du récit d'un regard.

### Lecture d'une chaîne généalogique

Chaque signature encode :
- Les glyphes de tête : structures dominantes à cet état
- Les glyphes centraux : direction de la transformation
- Le glyphe final : marqueur d'état (`◊` fermé, `↻` bifurcation, `Ø` suspension)
- Le lien `⊸` : la résolution a été rouverte — le suivant en est l'héritier

## Delta structurel NEXUS-ARCHÊ

La réversibilité permet une mesure du voyage réel sur toute la trajectoire.

En comparant les constellations NEXUS-ARCHÊ de tous les T0, KAIROS produit
un **delta structurel** — une carte de ce qui a persisté, bougé, émergé ou disparu.

### Protocole de delta

1. Lister toutes les constellations T0 archivées (grain long ou généalogie > 2)
2. Identifier par carte :
   - **Persistance** : carte présente dans tous les T0 → structure ancrée
   - **Dissolution** : carte présente en T0¹ absente en T0ⁿ → transformation réelle
   - **Émergence** : carte absente en T0¹ présente en T0ⁿ → nouveau territoire
   - **Oscillation** : carte apparaissant et disparaissant → tension non résolue

3. Formuler le delta en une phrase :
   *"Sur N cycles, [structure] s'est maintenue — [structure] a disparu — [structure] est apparue."*

### Exemple de lecture delta

```
T0¹ : CONTRAINTE ⊘ · POLARITÉ ⥀ · INCERTITUDE Ø
T0² : CONTRAINTE ⊘ · TRANSFORMATION ∿ · INCERTITUDE Ø
T0³ : ÉMERGENCE ⊙ · TRANSFORMATION ∿ · RÉCIPROCITÉ ⊗

Delta :
  Persistance  : TRANSFORMATION ∿ depuis T0² — elle s'est stabilisée
  Dissolution  : CONTRAINTE ⊘ disparue en T0³ — structure libérée après 2 cycles
  Émergence    : ÉMERGENCE ⊙ et RÉCIPROCITÉ ⊗ nouvelles — nouveau territoire ouvert
  Dissolution  : POLARITÉ ⥀ et INCERTITUDE Ø disparues — tension résolue
```

## Limites de la réversibilité

### Limite de profondeur par session

Profondeur maximale recommandée par session : **3 niveaux** de généalogie.
Au-delà, le risque est la spirale récursive sans progression réelle.

Si un quatrième niveau s'annonce dans la même session :
- Marquer une pause
- Archiver l'état courant
- Proposer de revenir à une session dédiée

### Détection de boucle récursive

Signal d'alarme : CRC-R produit les mêmes attracteurs qu'une session précédente
à ≥ 90%. Ce n'est pas une réouverture — c'est une boucle.

Protocole si boucle détectée :
1. Signaler explicitement : *"Ce cycle reproduit les attracteurs de [session N]."*
2. Ne pas relancer un cycle CRC-R sur le même stimulus
3. Demander : *"Quelle nouvelle matière a changé depuis la dernière fois ?"*
4. Si aucune nouvelle matière → suspension narrative (pas de résolution forcée)

### Réouverture depuis une branche ouverte

Si la résolution précédente était ouverte (`↻`), la réouverture s'ancre
sur l'une des deux branches — le sujet choisit son point de départ.

La branche non choisie n'est pas perdue : elle reste dans le journal
et peut être explorée lors d'une session ultérieure.

---

## Réversibilité depuis une suspension

Une suspension narrative (`Ø`) peut aussi être rouverte — mais le mécanisme
est différent.

La suspension indique que le récit manquait de matière. La réouverture n'est
possible que si de nouvelle matière est disponible :
- Un événement s'est produit
- Le sujet a une nouvelle perspective sur l'ancienne situation
- Une information manquante est désormais connue

Sans nouvelle matière → la suspension reste suspension. Ne pas forcer.

## Journal et réversibilité

Le `journal-stele.md` est l'infrastructure technique de la réversibilité.
Il archive toutes les entrées KAIROS avec leurs signatures, leurs états,
et les liens généalogiques.

Pour activer la réversibilité dans une nouvelle session :
1. Fournir le `journal-stele.md` à l'initialisation
2. KAIROS (via CRC-R Étape 0A) lit les 10 dernières entrées
3. Les attracteurs hérités sont calculés automatiquement
4. La généalogie est reconstruite avant le premier tirage NEXUS-ARCHÊ
