# KAIROS — Guide de lecture

> *Kairos : l'instant qualitativement juste. Non pas quand le temps passe,*
> *mais quand les conditions sont réunies.*

---

## Qu'est-ce que KAIROS

KAIROS est un modèle de résolution d'histoires. Il prend un récit — personnel,
collectif, fictionnel, stratégique — et le traite jusqu'à l'un de ses trois
états possibles : résolution fermée, résolution ouverte, suspension narrative.

Ce n'est pas un générateur de fins. C'est un détecteur de conditions : le modèle
identifie quand un récit peut légitimement se refermer, quand il bifurque de façon
valide, ou quand il manque encore de matière pour aller quelque part.

---

## Quand activer KAIROS

- Un récit tourne en rond et n'arrive pas à se clore
- Un arc narratif cherche son dénouement
- Un cycle de vie veut être relu dans sa trajectoire
- Une situation collective ou stratégique demande une résolution scenarrisée
- Un récit personnel porte une transformation que l'on veut valider
- On veut savoir où une histoire peut aller et à quelles conditions

---

## Ce que KAIROS produit

Selon où le récit atterrit, KAIROS produit :

| État | Ce que c'est |
|---|---|
| **Résolution fermée** | Le récit a atteint une stabilité structurelle réelle. Une transformation documentée. |
| **Résolution ouverte** | Deux branches coexistent. Aucune ne s'impose. L'histoire attend un événement extérieur. |
| **Suspension narrative** | Le récit n'a pas assez de matière pour se résoudre. Il faut plus de réel. |

Le format de cette sortie — bloc structuré, narration, ou les deux — est choisi par
le lecteur après que l'état a été présenté.

---

## Les quatre couches

KAIROS articule quatre skills existants dans l'ordre suivant :

```
NEXUS-ARCHÊ     Photographie les structures invariantes du récit
                → Quelles forces tiennent la situation au départ et à la fin

LÉR-NARRATIF    Parse le récit en couches de sens et l'ancre après transformation
                → La phrase dominante, les archétypes actifs, la réécriture

CRC-RÉCURSIF    Fait tourner le moteur de transformation jusqu'à stabilisation
                → Cristallisation, bifurcation ou suspension

MIROIR-INTÉGRAL Valide que le sujet a réellement changé (grain long, récit personnel)
                → La résolution correspond-elle à une transformation intérieure réelle ?
```

Chaque couche a un rôle précis. KAIROS ne les fusionne pas — il les fait travailler
en séquence et en dialogue.

---

## Les deux grains

**Grain moyen — arc narratif**

Un segment avec un début, une crise, et une clôture possible. Un chapitre, un projet,
une phase relationnelle, un épisode. Le modèle tourne en 3 à 5 cycles CRC et produit
une résolution dans la même session.

**Grain long — cycle de vie**

Un récit qui traverse plusieurs arcs, porte des motifs récurrents, touche à l'identité.
Le modèle fonctionne sur plusieurs sessions. Le journal STÈLE de CRC-R devient la
colonne vertébrale mémorielle — les attracteurs se transmettent d'une session à l'autre.

---

## La réversibilité

Aucune résolution n'est définitive. Toute résolution fermée peut être rouverte.

Quand c'est le cas, la signature STÈLE de la résolution précédente devient l'état
hérité du nouveau cycle. NEXUS-ARCHÊ peut mesurer le déplacement structurel entre
le T0 original et le T0 actuel — montrer combien l'histoire a réellement bougé
sur toute sa trajectoire.

```
T0¹ ──[KAIROS]──→ Trés¹
                    │
                   rouvrir
                    │
T0² ──[KAIROS]──→ Trés²  ← avec mémoire de Trés¹
```

---

## Le format de sortie

KAIROS ne prescrit pas comment la résolution doit être présentée. Une fois l'état
déterminé, trois options sont proposées au lecteur :

- **Bloc structuré** — pour archiver, comparer, analyser les états
- **Narration** — pour transmettre, ressentir, ancrer la transformation
- **Les deux** — le bloc pour soi, la narration pour l'autre

Le point de chute du récit informe naturellement ce choix.

## Relation aux autres skills de l'écosystème

| Skill | Relation |
|---|---|
| **NEXUS-ARCHÊ** | Composant actif — invoqué à chaque instantané structurel |
| **CRC-RÉCURSIF** | Composant actif — moteur principal de transformation |
| **LÉR-NARRATIF** | Composant actif — grammaire et ancrage |
| **MIROIR-INTÉGRAL** | Composant conditionnel — couche sujet |
| **STÈLE** (standalone) | Non invoqué — remplacé par le modèle STÈLE interne de CRC-R |
| **FRACTALES DU DESTIN** | Complémentaire — peut accompagner mais hors protocole core |
| **OSINT-INTEL** | Complémentaire en Mode B pour validation de scénarios |
| **SUPERFORECASTING** | Complémentaire pour les résolutions à valeur prédictive |

## Démarrage rapide

```
1. Soumettre un récit ou une situation narrative
2. KAIROS détecte le grain (moyen / long) et le mode (A / B / C)
3. NEXUS-ARCHÊ photographie la structure initiale
4. LÉR-NARRATIF parse les couches de sens
5. CRC-RÉCURSIF tourne jusqu'à cristallisation, bifurcation ou suspension
6. L'état de résolution est présenté
7. Le lecteur choisit le format de sortie
8. La mémoire STÈLE est générée pour continuité inter-sessions
```

---

> *KAIROS est un outil d'écosystème. Il requiert les skills NEXUS-ARCHÊ, LÉR-NARRATIF et CRC-RÉCURSIF. Pour des récits courts ou un usage standalone, il n'est pas le bon outil.*
